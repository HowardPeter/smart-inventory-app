Load-1000 generated approximately 78.9 RPS with 1,000 concurrent virtual users and 10–15 seconds of think time. The test produced 58.19% request errors, consisting of 48.81% HTTP 429 responses and 9.36% HTTP 500 responses. Lambda reached a peak concurrency of 517 with zero Lambda throttles. Application logs identified PostgreSQL connection exhaustion (EMAXCONN, 200-client limit) and AWS Systems Manager Parameter Store throttling as backend-side failure conditions. Therefore, at this workload, the system encountered downstream capacity constraints rather than Lambda concurrency throttling.
